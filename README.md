# CircuitLib

เว็บโหมดมืดสำหรับอัปโหลดภาพชิ้นส่วนอิเล็กทรอนิกส์ ดูรายการชิ้นส่วน และเรียนรู้หน้าที่กับวิธีใช้เครื่องมือวัด 4 ชนิด

เปิดเว็บ: https://keenzachanathip-bit.github.io/Electronic-Components-Librarys/

เว็บสาธารณะบน GitHub Pages ใช้ลิงก์โมเดลจาก `.env.example` หากเปลี่ยนโมเดล ให้แก้ `VITE_TEACHABLE_MACHINE_MODEL_URL` ในไฟล์นี้แล้ว push ไปที่ `main` เพื่อ deploy ใหม่ ส่วนการทดลองบนเครื่องใช้ `.env.local`

## เริ่มใช้งาน

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal แล้วกดการ์ดอัปโหลดเพื่อเลือกรูป หลังเลือกไฟล์ป๊อปอัปจะแสดงแอนิเมชันสแกนรูปและแถบโหลดก่อน เมื่อวิเคราะห์เสร็จจึงแสดงรูป คลาสที่ทำนายได้ หน้าที่โดยย่อ วิธีต่อวงจร วิธีสังเกตขั้วและจุดต่อ GND รวมถึงภาพ diagram ตัวอย่างของชิ้นส่วนนั้น กรอบสีเขียวในภาพระบุจุด GND ของวงจรตัวอย่าง ไม่ใช่ตำแหน่งขาจริง วิธีต่อวงจรและวิธีสังเกตขั้วยังแสดงบนหน้าหลักด้วย คลาสที่ยังไม่มีข้อมูลวิธีต่อวงจรจะแสดงข้อความแจ้งไว้ หากยังไม่ได้ตั้งลิงก์โมเดล เว็บจะแสดงรูปและแจ้งว่ายังระบุคลาสไม่ได้ ในส่วนรายการชิ้นส่วนสามารถค้นหา กรองตามประเภท และกดการ์ดเพื่ออ่านวิธีสังเกต วิธีต่อวงจรเบื้องต้น ภาพ diagram และตัวอย่างการใช้งานได้ ส่วนเครื่องมือวัดแสดงภาพถ่ายจริง หน้าที่ และวิธีใช้โดยไม่ต้องอัปโหลดภาพ

กดปุ่ม × บนรูปเพื่อเอารูปที่อัปโหลดออกและล้างผลทำนาย ปุ่มนี้อยู่ทั้งบนหน้าหลักและในป๊อปอัป

## ทดลองต่อวงจรหลังจำแนกภาพ

ผลที่โมเดลให้อันดับหนึ่งต่ำกว่า 75% หรือห่างอันดับสองไม่ถึง 15 จุด จะให้ผู้ใช้ยืนยันชนิดชิ้นส่วนก่อนแสดงวิธีต่อวงจร ผู้ใช้เลือกคลาสอื่นเองได้แม้คะแนนอันดับหนึ่งสูง เกณฑ์นี้มีไว้ช่วยเตือนให้ตรวจสอบ ไม่ใช่ค่าความแม่นของโมเดลที่ผ่านการทดสอบ

ถ้าคะแนนคลาสอันดับหนึ่งไม่เกิน 70% เว็บจะแสดงคำเตือนให้ลองอัปโหลดรูปใหม่ทั้งในป๊อปอัปและหน้าผลวิเคราะห์ โดยไม่แสดงคำเตือนนี้ในโหมดผลจำลอง

คลาส LED และ Resistor มีบททดลองเริ่มต้นร่วมกัน: แหล่งจ่าย DC 5 V → ตัวต้านทาน 330 Ω → LED สีแดง → GND พร้อมภาพตำแหน่งรูบน breadboard รายการอุปกรณ์ ขั้นตอนต่อสาย ผลที่ควรเห็น และวิธีตรวจเมื่อไฟไม่ติด เปิดได้ทั้งจากผลจำแนกและการ์ดรายละเอียด ภาพนี้เป็นตัวอย่างสำหรับชิ้นส่วนตามที่ระบุเท่านั้น ก่อนต่อไฟให้ตรวจขั้วและพิกัดของชิ้นส่วนจริง

คลาส Button Switch, Diode และ Transistor มีบททดลองแรงดันต่ำ 5 V เพิ่มเติม แต่ละบทมีรายการอุปกรณ์ ผังเส้นทางไฟ ภาพตำแหน่งรูบน breadboard ตารางจุดต่อสาย ขั้นตอนลงมือ ผลที่คาดหวัง และวิธีตรวจเมื่อไม่ทำงาน สำหรับ Transistor ใช้ตัวอย่าง NPN 2N3904 พร้อมลิงก์ datasheet เพื่อตรวจขา E/B/C จริงก่อนต่อ

ส่วน **เครื่องมืออ่านค่าสีตัวต้านทาน** ใช้ได้โดยไม่ต้องอัปโหลดรูป: เลือกสี 4 หรือ 5 แถบเพื่ออ่านค่า Ω และค่าคลาดเคลื่อน เปิดได้จากปุ่มหน้าแรก ลิงก์ในส่วนวิเคราะห์ภาพ และหน้ารายละเอียด Resistor

ไลบรารีวิเคราะห์ภาพจะโหลดเมื่อเปิดหน้าวิเคราะห์ภาพเป็นครั้งแรก เพื่อลดขนาดไฟล์ที่ต้องดาวน์โหลดตอนเปิดหน้าเว็บ ป๊อปอัปบนจอเล็กใช้พื้นที่แสดงรูปน้อยลงเพื่อให้เลื่อนถึงผลวิเคราะห์ง่ายขึ้น

ภาพถ่ายเครื่องมือวัดเก็บไว้ใน `public/images/tools/` โดยมีลิงก์แหล่งที่มา ผู้สร้าง และสัญญาอนุญาตแสดงบนการ์ดแต่ละใบ ภาพที่ใช้เป็นภาพย่อจาก Wikimedia Commons

## โมเดลที่ใช้อยู่

`.env.local` ตั้งโมเดลจริง `https://teachablemachine.withgoogle.com/models/mZNDylZHP/` และปิดโหมดจำลองแล้ว โมเดลมี 14 คลาส เว็บจะแสดงชื่อที่อ่านง่ายพร้อมชื่อคลาสดิบของโมเดล และจับคู่ `c_electrolyte`, `button_switch`, `ldr`, `7segment`, `phototransistor` กับข้อมูลและภาพวงจรที่ตรงชนิด โดย `button_switch` แสดงเป็น Button Switch พร้อมวิธีดูคู่ขาและตัวอย่างการต่อปุ่มกด

หากต้องการทดลองผลจำลองอีกครั้ง ให้ลบลิงก์ใน `VITE_TEACHABLE_MACHINE_MODEL_URL` และตั้ง `VITE_ENABLE_MOCK_MODEL=true` แล้วเริ่ม `npm run dev` ใหม่ โหมดนี้ **ไม่ได้วิเคราะห์ภาพจริง** และใช้ได้เฉพาะ dev server

## เปลี่ยนโมเดลทำนายภาพ

เปิดไฟล์ `.env.local` ที่อยู่ข้าง `package.json` และเปลี่ยนลิงก์หลังเครื่องหมาย `=`:

```env
VITE_TEACHABLE_MACHINE_MODEL_URL=https://teachablemachine.withgoogle.com/models/YOUR_MODEL_ID/
```

แทน `YOUR_MODEL_ID` ด้วยรหัสโมเดลใหม่ จากนั้นหยุดและเริ่ม `npm run dev` ใหม่ ลิงก์โมเดลจะไม่แสดงบนหน้าเว็บ โมเดลจะเริ่มโหลดหลังเปิดป๊อปอัปอัปโหลดภาพ และแถบความคืบหน้าจะแสดงค่าที่ตัวโหลดโมเดลรายงาน เมื่อโหลดโมเดลได้ เลขจำนวนชิ้นส่วนและรายการชิ้นส่วนจะเปลี่ยนตามคลาสในโมเดลโดยอัตโนมัติ หากคลาสใหม่ยังไม่มีข้อมูลวงจร เว็บจะแสดงข้อความแจ้งไว้

```powershell
npm run build
```

คำสั่งสุดท้ายใช้ตรวจ production build
